# Simple Python ATM Machine

A basic command-line ATM simulator built with Python to demonstrate core programming fundamentals.

## Features

- **User Authentication:** Secure PIN verification before accessing account options.
- **Check Balance:** View current account balance instantly.
- **Deposit Funds:** Add money to the account balance.
- **Withdraw Funds:** Cash withdrawal with automatic balance validation.
- **Simple Interface:** Easy-to-use menu-driven terminal interface.

## Prerequisites

- Python 3.x installed on your system.
